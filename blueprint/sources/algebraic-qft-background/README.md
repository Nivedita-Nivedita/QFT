# Source: standard algebraic QFT background

Some of [book 5](../../roadmap/yang-mills-millennium-problem/README.md)'s
Haag-Kastler-picture content formalizes standard structural definitions
from the algebraic QFT literature, rather than transcribing them from a
single text already in this project's library the way the rest of book 5
transcribes Jaffe-Witten's problem statement or Glimm-Jaffe's axioms.

- **The spectral condition** (positivity of the energy) is already implicit
  in the Jaffe-Witten problem statement's own description of a QFT as
  carrying a "positive-energy unitary representation" — see
  `blueprint/sources/yang-mills-millennium-problem/README.md`, item 1.
- **Cyclic and separating vacuum vectors**, and their relation to the
  Reeh-Schlieder theorem, are standard textbook material, most commonly
  associated with R. Haag, *Local Quantum Physics: Fields, Particles,
  Algebras* (Springer, 2nd ed., 1996), Ch. III. No copy of this book is
  currently in this project's library, so this repository does not cite a
  specific page, section, or theorem number from it — the definitions
  recorded here are standard enough to state confidently as definitions,
  but any precise pinpoint citation would be unverified and is
  deliberately avoided.
