# Gauge theory and four-manifolds: reference library

Eight standard textbooks on the differential geometry of gauge theory and
its applications to smooth four-manifold topology, catalogued as a
reference library rather than a single formalization target. See
[sources/gauge-theory-references/README.md](../../sources/gauge-theory-references/README.md)
for full citations and tables of contents.

**Status: no formalization target chosen.** Unlike the other books in this
repository, these were added as a collection to draw on later — e.g. as
background for the Euclidean-field and gauge-field prerequisites elsewhere
in this project — rather than because a specific theorem here is the goal.

## Foundational texts

- Hamilton, *Mathematical Gauge Theory*
- Sontz, *Principal Bundles* (2 vols.: *The Classical Case*, *The Quantum
  Case*)
- Frankel, *The Geometry of Physics*
- Naber, *Topology, Geometry and Gauge Fields* (2 vols.: *Foundations*,
  *Interactions*)

## Advanced: Yang-Mills theory and four-manifold topology

- Donaldson-Kronheimer, *The Geometry of Four-Manifolds*
- Freed-Uhlenbeck, *Instantons and Four-Manifolds*
- Scorpan, *The Wild World of 4-Manifolds*

## Plan

If and when one of these becomes an actual target, follow the same process
as the other books in this repository (see the repository's top-level
`README.md`, "Adding a new book" section): obtain a
legitimate copy, read the target chapter closely and record exact
statements in `sources/gauge-theory-references/`, draft a coarse milestone
chapter here, get it reviewed, then decompose into Lean statement nodes.
