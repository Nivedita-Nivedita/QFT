# Phase transitions

Source: Glimm-Jaffe, Chapter 16, pp. 316-338.

Establishes the existence of a phase transition (multiple Gibbs states) for
the Euclidean `φ⁴` field when `σ` is sufficiently negative, and analyzes
symmetry breaking as a function of dimension. Cited directly on the opening
page of Chapter 17.

Sections in the source: 16.1 Introduction (316); 16.2 The Two Phase Region
(320); 16.3 Symmetry Unbroken, d = 2 (330); 16.4 Symmetry Broken, 3 ≤ d
(333).
