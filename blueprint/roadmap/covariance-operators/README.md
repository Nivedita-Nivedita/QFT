# Covariance operators

Source: Glimm-Jaffe, Chapter 7, pp. 159-179.

The covariance operator `C` is simultaneously the Green's function, the
resolvent kernel, the Euclidean propagator, and the fundamental solution of
`(-Δ + m²)C = δ`. Its dependence on boundary conditions and its reflection
positivity are used to build the interacting measure in later chapters.
