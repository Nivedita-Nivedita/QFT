# Yang-Mills Existence and Mass Gap

Formalizing the self-contained mathematical content of Jaffe and Witten's
Clay Mathematics Institute problem statement itself, as opposed to the
literature it cites (already covered, where formalized at all, by this
project's other books). See
[sources/yang-mills-millennium-problem/README.md](../../sources/yang-mills-millennium-problem/README.md).

## Chapters

1. [Axiomatic quantum field theory](axiomatic-qft/README.md) — the
   Wightman-style axioms, the mass gap, and the mass operator, as defined in
   §3-4 and §6.2 of the problem statement.
2. [The Millennium Problem statement](millennium-statement/README.md) — the
   actual conjecture, formalized as a precise (necessarily unproved) Lean
   statement.
3. [Clustering from a mass gap](clustering-theorem/README.md) — the one
   genuinely provable theorem the document states outright: a mass gap
   implies exponential decay of correlations.

Formalizing the conjecture precisely, and proving the one real theorem the
document states, is real, checkable work — but it does not constitute
progress on the open problem itself, and should never be described that
way.
