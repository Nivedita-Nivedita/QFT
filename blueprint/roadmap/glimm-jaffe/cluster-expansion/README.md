# The cluster expansion

Source: Glimm-Jaffe, Chapter 18, pp. 356-378.

A convergent expansion valid away from the critical point (close to
Gaussian), used in Chapter 17 to rule out a phase transition when `σ` is
large. Forward-cited on the opening page of Chapter 17.
