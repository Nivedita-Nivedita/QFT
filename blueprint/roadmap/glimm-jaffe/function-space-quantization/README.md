# Quantization on function space

Source: Glimm-Jaffe, Chapters 8-9, pp. 180-228.

Quantization is realized as integration over function space against a
Gaussian measure of covariance `C`, perturbed by the interaction. This
chapter builds the finite-volume, finite-cutoff interacting measure and its
perturbative renormalization, which the later chapters remove cutoffs from.

Sections in the source (Ch. 8, "Quantization = Integration over Function
Space", p. 180): 8.1 Introduction (180); 8.2 Feynman Graphs (181); 8.3 Wick
Products (183); 8.4 Formal Perturbation Theory (186); 8.5 Estimates on
Gaussian Integrals (188); 8.6 Non-Gaussian Integrals, d = 2 (193);
8.7 Finite Dimensional Approximations (199).

Sections in the source (Ch. 9, "Calculus and Renormalization on Function
Space", p. 202): 9.1 A Compilation of Useful Formulas (202); 9.2
Infinitesimal Change of Covariance (210); 9.3 Quadratic Perturbations (211);
9.4 Perturbative Renormalization (215); 9.5 Lattice Laplace and Covariance
