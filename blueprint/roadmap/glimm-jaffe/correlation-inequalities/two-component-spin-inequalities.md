# Two-component spin correlation inequalities

For vector-valued ("two-component") spins `ξ_i = (ξ_i¹, ξ_i²)` with
Hamiltonian `H = -Σ J_{ij} ξ_i·ξ_j - Σ h_i·ξ_i` (`J_{ij}, h_i² ≥ 0`) and an
`SO(2)`-invariant single-spin distribution with quartic interaction
`P_i(ξ_i) = λ_i(ξ_i·ξ_i)² + σ_i(ξ_i·ξ_i)`, the analogues of the Griffiths and
Lebowitz inequalities hold in the coordinates `t_i = ξ_i¹, q_i = ξ_i²`:
`0 ≤ ⟨t^Aq^B⟩`, `0 ≤ ⟨t^At^B⟩ - ⟨t^A⟩⟨t^B⟩`, `0 ≤ ⟨q^Aq^B⟩ - ⟨q^A⟩⟨q^B⟩`, and
`0 ≤ ⟨t^A⟩⟨q^B⟩ - ⟨t^Aq^B⟩`. The proof follows the same duplicate-variable
pattern as the [second Griffiths](second-griffiths-inequality.md) and
[ξ⁴](xi4-inequalities.md) inequalities, since `P(ξ) + P(ξ')` decomposes as an
even function plus a ferromagnetic term `-4λαβγδ`. Two special cases give
`0 ≤ ⟨(Π_{i∈A}ξ_i¹)(Π_{j∈B}ξ_j²)⟩` and `0 ≤ ⟨ξ_i·ξ_j⟩ - ⟨ξ_i⟩·⟨ξ_j⟩`.
