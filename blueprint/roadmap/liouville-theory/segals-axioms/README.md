# Segal's axioms

Source: Guillarmou, Kupiainen, Rhodes, Vargas, "Segal's Axioms and Bootstrap
for Liouville Theory" [4]. See
[sources/liouville/README.md](../../../sources/liouville/README.md). This is
the project's target chapter for this book.

A probabilistic implementation of Segal's 1987 functorial axioms for
conformal field theory, within Liouville CFT. Expresses LCFT correlation
functions as multiple integrals, over the theory's spectrum, of Virasoro
conformal blocks (built from the previous chapter's highest-weight modules)
weighted by an integration measure built from the DOZZ structure constants.

Not yet read in the same page-by-page detail as the survey; citations only.
