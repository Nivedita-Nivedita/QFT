# Conformal bootstrap

Source: Guillarmou, Kupiainen, Rhodes, Vargas, "Conformal Bootstrap in
Liouville Theory" [3]. See
[sources/liouville/README.md](../../../sources/liouville/README.md).

The first mathematical proof of the conformal bootstrap hypothesis for
Liouville theory: correlation functions are reconstructed from Virasoro
conformal blocks together with the DOZZ structure constants of the previous
chapter. Constructs Virasoro-algebra highest-weight modules via spectral
analysis of a self-adjoint operator; the result holds for the whole possible
parameter range `γ ∈ (0,2)`.

Not yet read in the same page-by-page detail as the survey; citations only.
