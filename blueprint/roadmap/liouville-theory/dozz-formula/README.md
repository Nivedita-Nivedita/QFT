# The DOZZ formula

Source: Kupiainen, Rhodes, Vargas, "Integrability of Liouville Theory: Proof
of the DOZZ Formula" [2]. See
[sources/liouville/README.md](../../../sources/liouville/README.md).

Proves the DOZZ (Dorn-Otto-Zamolodchikov-Zamolodchikov) formula: an explicit
closed-form expression for the three-point structure constants of Liouville
CFT, derived from the sphere correlators of the previous chapter using a
rigorous probabilistic (Gaussian multiplicative chaos) argument. Described
by the authors as the first rigorous integrability result for GMC measures
from a purely probabilistic point of view.

Not yet read in the same page-by-page detail as the survey; citations only.
